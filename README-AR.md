# الدروبي للصرافة والتحويلات المالية — التحقق من المدفوعات

نسخة مخصصة لعلامة الدروبي للصرافة والتحويلات المالية مبنية على مشروع Cheki مفتوح المصدر. الهدف هو التحقق من إيصالات التحويلات الإثيوبية بالرجوع إلى مصدر البنك، وليس الاكتفاء بصورة الإيصال أو بيانات QR.

## قواعد التحقق المهمة

- لا تعرض العملية على أنها مؤكدة إلا عندما يؤكد مصدر البنك ذلك صراحةً (verified: true).
- إذا كانت النتيجة decodedOnly: true فهي بيانات QR مقروءة فقط وليست إثباتاً بنكياً.
- نتائج OCR أو النصوص المدخلة من المستخدم لا تعتبر تأكيداً من البنك.
- قد لا يمكن فحص Telebirr وM-Pesa مباشرةً من الخوادم السحابية؛ اتبع رابط المصدر الرسمي عند إرجاعه ولا تعرضها كمؤكدة تلقائياً.

## التشغيل محلياً على Windows

يتطلب Node.js متوافقاً مع المشروع وnpm.

1. نزّل المستودع وافتح مجلده في VS Code.
2. افتح Terminal داخل المجلد.
3. نفّذ الأوامر التالية:

   npm install

   npm test

   npm run dev

4. افتح العنوان المحلي الذي يظهر في الطرفية.

## إعداد الإنتاج

- لا تضع كلمات المرور أو مفاتيح الوصول داخل GitHub.
- استخدم متغيرات البيئة في منصة الاستضافة.
- لا تضع عنوان قاعدة بيانات أو كلمة مرور حقيقية في .env.example.
- استخدم HTTPS، وصلاحيات منفصلة لكل محل، وعزل بيانات المحلات في قاعدة البيانات قبل الاستخدام التجاري.
- اختبر اتصال Cheki الحقيقي من بيئة الاستضافة قبل الاعتماد على النتائج.

## حالة المشروع

هذه نسخة عمل مبنية على Cheki مع بيانات تعريف للمشروع الجديد. يلزم إكمال مراجعة واجهة العربية/RTL، وحسابات المدير والمحلات والاشتراكات، وربط PostgreSQL وسياسات العزل، ثم تشغيل الاختبارات والبناء والنشر قبل وصفها بأنها جاهزة للإنتاج.
